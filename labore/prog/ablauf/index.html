    Was dieses Labor zeigt und was nicht
    
    
      
  • Die Programme wurden vorab mit echtem Python ausgeführt und Schritt für Schritt aufgezeichnet. Was Sie sehen, ist also genau das, was Python tut, einschließlich der Werte wie 154.01999999999998.
    • 
      
  • Eigener Code kann hier nicht eingegeben werden. Dafür nutzen Sie Jupyter.
    • 
      
  • Die Eingaben wählen Sie oben aus. In Jupyter tippen Sie sie in das Eingabefeld unter der Zelle.
    • 
      
  • Python kennt „Zeilen“ eigentlich nicht als Schritte. Zeilen wie else: werden deshalb nie selbst markiert, sondern gleich die erste Zeile darunter.
    • 
      
  • Der PAP verwendet die Sinnbilder nach DIN 66001: Oval für Start und Ende, Rechteck für Anweisungen, Parallelogramm für Ein- und Ausgabe, Raute für Verzweigungen. Mehrere gleichartige Zeilen sind zu einem Kasten zusammengefasst.
